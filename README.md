Hero vs. Monster

A turn-based RPG console application developed in C# using .NET 10.

Features
- Randomized combat and damage calculations.
- Critical hits and healing potions.
- Defensive mechanics, including blocking and parrying.
- Enemy transformations and multiple combat phases.
- Auto-revive mechanic.
- Replay functionality.
Technologies
- C#
- .NET 10
- Visual Studio 2022
How to Run

Clone the repository, open the solution in Visual Studio, and run the application using Ctrl + F5.
